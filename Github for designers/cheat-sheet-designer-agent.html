❌ 不要說的話Phrases to avoid

這些字會讓 Agent 觸發破壞性指令，或語意模糊讓 Agent 猜錯動作。 These trigger destructive commands or are too vague — the agent may guess wrong.

不要說Avoid 為什麼Why 改說Say instead
「強推」「force」「硬上」"force", "push hard" 觸發 --force，會蓋掉遠端別人的工作Triggers --force, overwrites teammates' work 「push 被擋了，幫我處理」"Push rejected, please handle it"
「蓋過去」「直接覆蓋」"overwrite it", "just replace" 同上，可能 silent overwriteMay silently overwrite remote 「整合進去」「合併」"integrate it", "merge it"
「全部清掉」「重置」"clear everything", "reset" 觸發 reset --hard，本機未 commit 改動會消失Triggers reset --hard, uncommitted edits lost 「丟掉 X 檔的改動」（指定範圍）"Discard changes in X file" (specify scope)
「拉下來」"pull it down" (vague) 分不清 pull / fetch / clone / checkout，Agent 可能猜錯Ambiguous between pull / fetch / clone / checkout 「pull 遠端最新的」或「clone 這個 repo」"Pull latest from remote" or "Clone this repo"
「推上去」"push it up" (vague) 分不清 push / force push / merge / PRAmbiguous between push / force / merge / PR 「push 到目前 branch」或「開 PR 合到 main」"Push to current branch" or "Open PR to main"
「連結」「接起來」"link it", "connect them" 分不清 merge / rebase / submodule / remote addAmbiguous between merge / rebase / submodule / remote 「把 X branch merge 到 Y」"Merge branch X into Y"
「不管衝突直接合」"just merge, ignore conflicts" 可能 silent overwrite，丟失改動May overwrite silently, losing changes 「把衝突列出來給我看」"Show me the conflicts"

📘 基本操作建議用語Recommended base vocabulary

固定用這些字，Agent 就不會誤解。 Use these consistently and the agent won't misread you.

clone

First-time copy a repo
pull

Bring remote updates local
push
把本機 commit 推到遠端
Send local commits to remote
commit

Record a local version

Open a parallel work line

merge

救援三步驟When in doubt — three questions

1 「我現在的狀態是什麼？」 — 確認在哪條 branch、有沒有未存的改動"What state am I in?" — current branch, unsaved edits
2 「這個操作會影響到誰？」 — 只動本機，還是會推到遠端"Who does this affect?" — local only, or pushed to remote
3 「有沒有更安全的做法？」 — 永遠先問再做"Is there a safer way?" — ask before acting

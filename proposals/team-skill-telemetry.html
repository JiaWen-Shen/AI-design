06 / 09
技術原理

純 git，無外部服務

記錄
Claude Code PreToolUse hook，攔 tool_name == "Skill" 且 skill 在 hie-rei allowlist 內 → append 一行 JSON 到本機 ~/.claude/team-skill-telemetry/events.jsonl
同步
每週一 09:23 launchd 觸發 weekly-sync.sh：
1. mktemp -d 建暫存 → gh repo clone --depth 1
2. 篩本週事件 → raw/<user>-<week>.jsonl
3. aggregate.py 重生 weekly-*.md + weekly-latest.md
4. commit + push (rebase-retry on conflict)
5. rm -rf $TMP
多人衝突
每個人有自己的 <user>-<week>.jsonl，永不撞檔。週報 markdown 用 deterministic 生成，誰最後 push 內容都一樣 → pull-rebase-retry 自然收斂。
失敗處理
cron 失敗只 log 到 ~/.claude/team-skill-telemetry/sync-errors.log，下週再補；不阻斷 session。

FAQ · 聯絡

常見問題

「我不想被記錄」

export SKIP_SKILL_TELEMETRY=1 加進 ~/.zshrc，就完全不記。

「Opt-out 後想看自己的歷史資料」

repo 內 raw/<your-slug>-*.jsonl 撈得到。

「我加了新 skill 到 hie-rei，要改 hook 嗎？」

不用。Allowlist 是動態讀 hie-rei/.claude/skills/ 目錄列表，新 skill 自動納入追蹤。

「想看的分析維度沒有」

aggregate.py 是 deterministic，新欄位歡迎 issue / PR；raw data 都還在 repo 內。

「想全部砍掉」

bash installer/uninstall.sh — launchd plist + hie-rei hook entry 移除。

「資料保留多久？」

v0.1 永久保留。視容量未來可改 90 天後歸檔。

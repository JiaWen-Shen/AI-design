1這份 prompt 幫你做三件事

  • Switch to C4E account — 從 RDsec AI proxy 切到 Trend Micro Claude Enterprise（SSO）
  • Set default model = Opus 4.7 + effortLevel = high — 寫進 settings.json，新開 session 自動套。
    （Claude Code 在 Opus 4.7 預設 effort = xhigh，token 燒得快；鎖 high 省 ~30% 量同時保留智慧）
  • Enable 1hr prompt cache — TTL 從 5 分鐘改 1 小時，跨會議 cache 不掉、省 token

三件事獨立檢查、獨立 skip：已做過的不重跑。最後 agent 自動回報 Karen。

✅ 可重跑當 health-check：已設定完的人也可以丟一次，Step 0 偵測 7/7 ✅ → 顯示「你已經就緒」+ 只發一筆 auto-report，不會改任何東西。

4自動回報（Google Sheet 全自動）

環節怎麼跑需要用戶動作？
Agent 端curl -X POST JSON payload 到 Apps Script Web App endpoint否 — 整段 prompt 內
Apps Script 端doPost() 接 JSON、dedupe by (hostname, app)、覆寫或 append否 — Karen 已部署
Karen 端開 Google Sheet 看 adoption rate / device list否
Fallback（endpoint 不可達）payload 存 ~/Desktop/c4e-migration-<hostname>.json，提示拖到 Teams DM 給 Karen是 — 但僅 fallback

對設計師：跑完 prompt 就完成回報，不需要點任何東西、不需要 GitHub / Teams 權限、不需要 MFA。


## REVISED

```

```

## Changes Applied
- [W3] Both CTA buttons removed from detail page

## Advisory
**Action path gap**: With "Remove" and "Uninstall" removed, users who decide to act after reviewing have no visible mechanism. Confirm one of the following is present post-change:
- A tertiary link ("Uninstall from device settings")
- An info disclosure (e.g., "How to remove this app")

This is not a wording issue but surfaces from the wording review scope.

# Screen: Security Scan Detail (Android) — Annotation 3

## ORIGINAL

```
Uninstallation recommended
```

## REVISED (design proposal)

```
App Review
```

## REVISED (this review's recommendation)

```
App Security Review
```

## Changes Applied
- [W1] "Uninstallation recommended" → recommend "App Security Review" over "App Review"

## Rationale for W1
"App Review" without qualifier creates two risks:
1. **Platform confusion**: Users familiar with Google Play / Apple App Store associate "App Review" with store submission reviews — creates cognitive mismatch.
2. **Lost security signal**: The word "Uninstallation" (however aggressive) told users this was a security-driven screen. "App Review" without "Security" is agnostic.

"App Security Review" keeps the screen's purpose clear, matches the product category (mobile security), and avoids prescribing an action.

## Impact Radius
- "Review recommended" (main screen) + "App Security Review" (detail screen title) — both use "Review" ✅ consistent
- If implemented as "App Review" only, verify whether it reads consistently across languages (localization consideration)
